# 美股 ETF 推送内容增强建议

本参考记录日常推送在“已有市场信号 + 持仓换算”基础上，最值得补充的可执行内容。目标是让 Telegram 推送直接回答“今天我该怎么处理现有自动定投/人民币基金执行”，而不是只展示研究指标。

## P0：优先加入推送

### 1. 国内执行层 / QDII 溢价提醒

当研究层建议买入 SPY/QQQ 暴露时，人民币执行层应单独展示：

- 候选基金代码与名称。
- 跟踪指数：标普500 / 纳指100。
- 溢价率、成交额/流动性、申购状态。
- 执行动作：正常买 / 减半买 / 暂缓买。
- 数据更新时间；若 `qdii_universe.json` 过期，明确写“执行层数据过期，不作为下单依据”。

推荐规则：

- 溢价 <= 0.5%：正常执行。
- 0.5% < 溢价 <= 1.5%：减半或谨慎执行。
- 溢价 > 1.5%：暂缓。
- 申购暂停且溢价偏高：暂缓；若溢价正常，只能作为二级市场候选并提示风险。

### 2. 自动定投计划 vs 模型建议差额

推送必须把 `portfolio_config.json` 中的实际自动定投安排与模型建议对齐，直接展示差额：

- 模型建议总额 = 周基准 × 定投倍率。
- 当前自动定投总额 = `plan.items[]` 中 `status=active` 的 `weekly_equivalent` 总和。
- 本周若不调整，会比模型多买/少买多少。
- 分资产差额：标普类多买/少买多少，纳指类多买/少买多少。

示例表达：

```text
自动定投差额
- 模型建议：本期买 ¥1,500（标普 ¥600，纳指 ¥900）
- 当前自动单：本周约 ¥2,000（标普 ¥1,000，纳指 ¥1,000）
- 若不调整：总额多买 ¥500；标普多买 ¥400，纳指多买 ¥100
```

### 3. 本次推送触发原因 / 相比上次变化

去重字段变化时，推送里应说明“为什么今天推送”：

- 定投倍率变化：`1.0x → 0.75x`。
- 买入分配变化：`50/50 → 40/60`。
- Regime 变化：`expensive → very_expensive`。
- QQQ 减仓信号变化：`0% → 3%`。
- QDII 执行层状态变化：`正常 → 减半/暂缓`。

如果是强制推送或周报，而建议本身未变，写：

```text
建议未变，本次仅做状态复盘。
```

## P1：可选增强

### 关键阈值预警

可在接近关键阈值时给一次提醒，但不要让它导致每日刷屏：

- CAPE 接近 42。
- RSI 接近 75 / 78。
- VIX 接近 25 / 30。
- SPY 接近跌破 SMA200。

### 减仓信号突出显示

减仓是提醒，不是自动交易。触发时单独成块：

```text
⚠️ 减仓提醒：QQQ 3%
- 规则：CAPE >= 42 且 RSI >= 75
- 这是提醒，不自动执行
- 如已实际执行，再记录 trim state，避免本月重复提醒
```

### 周报/月报分层

- 日推送保持短，只推操作建议和核心指标。
- 周报可加入本周 SPY/QQQ 涨跌、实际定投 vs 模型建议差额、持仓偏离、下周自动单调整建议。
- 回测指标、XIRR、胜率等适合月报或规则变更后推，不适合每天推。

## 不建议加入日推送

- 不要每天推完整回测。
- 不要每天推长篇策略解释。
- 不要加入过多宏观新闻解读，避免稀释操作信号。
- 不要只停留在 SPY/QQQ ticker；必须继续落到人民币金额和实际基金执行。
